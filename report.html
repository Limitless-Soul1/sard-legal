Report an issue

Tell us what happened

Write your report here and it will be handed to GitHub with every field already filled in, so you can add screenshots and submit it in one step.

What kind of report is this?

One line that says what this is about.

What you did, what you expected, and what happened instead.

Sard's version (Settings → About), your version of Windows, and anything else that seems relevant.

Screenshots and files. Add them on the next screen — GitHub's own composer takes images and log files by drag-and-drop, and uploads them for you. That is the only place an attachment can be added properly, so this page does not pretend to take one.

What happens when you continue. Nothing is sent from this page. The button opens GitHub's report form for sard-legal with your text already in it; you review it, add any files, and press the button there. The issue is posted under your own GitHub account, which is what lets us reply to you.

Continue to GitHub

If you would rather not use GitHub

Submitting an issue needs a free GitHub account. If you do not have one and do not want one, use Copy as text above and send it by whatever route suits you — the copied text carries everything the form asked for.

Which repository this goes to

Reports go to sard-legal, which is this site's repository and the front door for everything: bugs, feedback, questions, and anything about the Terms or the Privacy Policy. Sard's own source lives in a separate repository, which is where you download the application — not where you need to file this.

الإبلاغ عن مشكلة

أخبِرنا بما جرى

اكتب بلاغك هنا، ثمّ يُسلَّم إلى GitHub وقد امتلأت خاناته كلّها، فلا يبقى عليك إلّا إرفاق الصور وإرساله في خطوة واحدة.

ما نوع هذا البلاغ؟

سطر واحد يبيّن موضوع البلاغ.

ما الذي فعلتَه، وما الذي توقّعتَه، وما الذي حدث بدلًا منه.

إصدار سَرْد (الإعدادات ← عن البرنامج)، وإصدار ويندوز لديك، وكلّ ما تراه ذا صلة.

الصور والملفّات. أضِفها في الشاشة التالية؛ فمحرّر GitHub نفسه يقبل الصور وملفّات السجلّ بالسحب والإفلات ويرفعها عنك. وهو الموضع الوحيد الذي يصحّ فيه الإرفاق، ولذلك لا تتظاهر هذه الصفحة بأنّها تقبله.

ماذا يحدث حين تتابع. لا يُرسَل شيء من هذه الصفحة. يفتح الزرّ استمارةَ البلاغ في sard-legal ونصّك فيها، فتراجعه وتُرفق ما شئت ثمّ تضغط الإرسال هناك. ويُنشَر البلاغ باسم حسابك أنت على GitHub، وبذلك يمكننا الردّ عليك.

المتابعة إلى GitHub

إن كنت تفضّل ألّا تستعمل GitHub

يحتاج إرسال البلاغ إلى حساب مجّاني على GitHub. فإن لم يكن لديك حساب ولم ترغب في إنشائه، فاستعمل نسخ النصّ أعلاه وأرسِله بالطريقة التي تناسبك؛ فالنصّ المنسوخ يحمل كلّ ما طلبته الاستمارة.

إلى أيّ مستودع يذهب هذا

تذهب البلاغات إلى sard-legal، وهو مستودع هذا الموقع وبابُ كلّ شيء: العلل والاقتراحات والأسئلة وكلّ ما يتّصل بالشروط أو بسياسة الخصوصية. أمّا شفرة سَرْد نفسها فتقيم في مستودع منفصل، وهو موضع تنزيل التطبيق لا موضع تقديم البلاغ.
